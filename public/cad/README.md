# CAD 实体建模执行器（实验性）

这是工程台的本地 CAD 执行模块。输入为已保存的 `cad-task-v1` JSON，输出为 STEP、BREP、STL、装配 STEP、参数源、建模步骤及检查记录。不会打印或控制设备。

## 安装与运行

本次实际验证环境为 Windows x64、Python 3.12.14、CadQuery 2.8.0、cadquery-ocp 7.9.3.1.1、CasADi 3.8.0、NLopt 2.9.0。请使用独立虚拟环境，依赖锁见 requirements-windows-py312.txt。锁文件来源为本次实际安装的 PyPI wheel；其他系统须单独验证依赖和运行时。

```powershell
python -m venv cad-env
.\cad-env\Scripts\python.exe -m pip install --require-hashes --only-binary=:all: -r requirements-windows-py312.txt
.\cad-env\Scripts\python.exe run_cad.py 任务.json --output 新结果.zip
```

下载任务后运行上述命令，再到同一 CAD 任务导入结果并加入当前设计。已存在输出文件不会被覆盖。参数改动后应创建新任务，历史工件仍保留。失败时没有可导入的结果包；调整设计后创建或重试任务，不应人工伪造成功记录。

## 能力与边界

支持每设计 1–12 个零件、每件最多 32 个有序特征、64 个数值参数和 24 个直孔接口。支持 box、cylinder、sphere、profile_extrude、union、subtract、intersect、fillet_all、fillet_edges；`profile_extrude` 只接受最多 24 点的闭合二维轮廓与固定 XY/XZ/YZ 平面，`fillet_edges` 只接受 X/Y/Z 平行边选择，不接受任意选择器或脚本。所有尺寸仅接受数值或参数的比例/偏移引用，不执行任务中的 Python 或自由脚本。每件必须为一个有效正体积实体。装配仅支持明确平移，不是装配约束求解器。

输出参数源保留稳定设计、零件和特征编号。STEP/BREP 是实体交换格式，本身不保留此参数历史。每件 STL 使用毫米、Z-up、零件局部坐标；装配位置另存。STL 采用绝对 0.05 mm 弦高参数、0.1 rad 角度参数；这些是网格化设置，不是打印精度承诺。

直孔检查仅作用于所声明的 Z 轴直孔区间：0.01 mm 数值偏置的内圆柱空腔检查，以及孔外薄环材料检查。它不是任意孔型、螺纹、配合或强度验证。零件两两求交报告交叠体积，不验证必要间隙；交叠不会自动被当作装配合格。实体有效性是 OCCT 默认 BRepCheck，STEP 回读比较有效性、实体数及体积，不是严格几何等价证明。

单次文件执行采用每任务独立进程、180 秒超时。自动连接模式另有持久 SQLite 台账、210 秒控制器期限和 Windows 进程组清理；没有操作系统级内存硬配额。结果压缩包上限 8 MB，解压上限 24 MB，在线导入每件最多 10 万三角面。超限应转到独立工程执行服务。

## 固定运行时与退出修正

controlled-cad-v2 使用 NLopt 2.9.0 与 CasADi 3.8.0，并正常结束解释器，不再调用强制退出绕过清理。此前 Windows pip 的 NLopt 2.11.0 / CasADi 3.8.0 组合即使只导入这两个库，也可出现退出时原生异常；固定上述兼容 wheel 后，受控建模、回读与重复运行均已通过。

这证明本次固定组合和已测受控工作流可正常运行，不代表所有 CAD 操作或生产环境均已验证。请按锁文件安装；不要随意升级 NLopt、CasADi 或 OCP。执行器会拒绝不匹配的关键依赖版本。旧 v1 归档仍可查看，不会被自动升级为 v2 证据。

## 自动连接

工程台 CAD 页可配对本机控制器，自动领取、生成和回传。详见同一交付包 executor/README.md。自动归档后仍需点击“加入当前设计”，避免在工程师修改草稿时覆盖页面。浏览器需保持打开才能传送任务及结果；本机计算本身由独立进程执行。

## 验证等级

工程台核对输入版本、参数源、文件清单、文件指纹、STL 尺寸及记录一致性。服务器没有独立重跑 CAD。内层报告仍标注 unsigned_local_report。手工上传没有执行来源认证；自动通道在外层添加已登记本机密钥的签名，并绑定任务、执行器文件与结果文件指纹。这能核验所登记密钥的来源，不能阻止具有本机控制权的人伪造行为，也不能证明 STEP/STL 严格等价或批准生产。实际打印、支撑、壁厚、承载、间隙、工艺校准和首件验证仍待完成。

导入网格不会自动恢复为参数化实体。当前 AI 接口可提出受控 CAD 新设计/参数修改，未配置真实服务时会明确拒绝请求；本次样例是工程代码和真实内核验证，不是已完成 AI 实调的证据。
