## 怎样演示

先双击桌面上的 `启动造物工程台.cmd`（桌面实际位于 `<user-desktop>`）。这只负责启动网页和后台服务；`生成8位配对码.cmd` 是另一份独立脚本，只负责给出本机 CAD 配对码。若需要从源码手动启动，才在项目目录运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/open-local-domain.ps1
```

启动器会检查构建、启动网页、生成连接和返工服务，再打开本地域名的 Edge。保持网络代理和 Docker Desktop 可用。不要把普通公网浏览器访问的同名网址当成本机演示。

### 1. 文字生成

1. 点“新项目”，填写项目名称、设计要求和目标尺寸。
2. 点“生成三维方案”，会跳到任务进度页。
3. 保持该页面打开、等待完成。第一份方案会自动加入项目，并回到三维视图；无需手工下载再导入。
4. 生成过程中不要改动项目版本；如果改过，系统会要求手工确认加入，避免覆盖修改。

已有验收结果：[文字生成项目](http://www.3dprinthub.cn/?project=ffef5616-f943-462e-9d53-fff72d86d0c8)。

如果中途关闭或刷新了页面，在“项目版本”查询原任务并加入项目，不要为了找回结果重复生成。多方案时自动显示第一份，其余可在任务列表查看。

### 2. 圈选返工

1. 双击桌面“生成8位配对码.cmd”。它只显示并复制配对码，不负责打开网页。在设计工坊中间模型区下方展开“连接本机建模”，把码填入“8 位配对码”，端口保持 8837，点“连接本机”。
2. 打开专用项目 v1，确认右侧选中“白色外壳”，中间显示 4 个零件。点模型区左下角“圈选修改区域”，按住鼠标，在白色外壳前侧表面画圈后松开。应显示“修改区域已标记”和“白色外壳 · 视角已锁定”；若显示其他零件，请重新选中白色外壳再圈选。
3. 在“AI 改版建议”输入：`将白色机身总宽从 136 mm 调整为 137 mm，四个 M3 安装孔和 USB-C 接口的位置、尺寸保持不变；其余零件不修改。` 点“生成返工计划”。
4. 核对计划确实修改白色外壳宽度、保留锁定接口，再点“批准并执行”。下方会显示规划、审批、执行、校验和模型载入的真实状态；如要求澄清，先按问题回答并重新核对计划。
5. 成功后会显示“返工完成”及新版本，也可点“查看修改后的模型”。物理打印验证仍未执行。

演示位置：应画圈的白色外壳截图（本机文件，未随仓库发布）。真实圈选后的页面（本机文件，未随仓库发布）中绿色圈是页面实际生成的标记；已验证它会随模型缩放重新投影。红圈只用于讲解，不是网页功能。

已有验收结果：[返工结果副本](http://www.3dprinthub.cn/?project=4fa97d05-f2c8-4c5e-9a77-9d4df256dbd6)。这个副本现在已经是 **138 mm**，再次修改时请填写基于当前尺寸的新要求，不要把 136 mm 当成当前值。

配对码只能使用一次、10 分钟内有效；再次双击桌面脚本会生成新码并重启本机 CAD 执行器，**建模任务运行中不要重启**。批准执行后保持网页打开，直到回传完成。

## 仍然没有实现的能力

1. **任意生成网格的精确局部修改**：当前返工针对有参数化来源的 CAD 制造件。Tripo 外观网格需要额外的局部网格编辑或工程重建能力，不是再填一个密钥就能补齐。
2. **任意设计要求一次变成可制造成品**：本次文字生成给出可旋转查看的外观模型，不保证每个开孔、壁厚、装配细节符合要求，更不代表已经打印验证。
3. **公网随处打开都能演示**：本次验收针对这台 Windows 电脑，服务和本机建模需在线；没有做公网部署或其他电脑的安装验收。
